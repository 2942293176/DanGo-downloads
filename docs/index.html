A FEW LITTLE ANSWERS

你可能
还想知道。

支持哪些电脑和形象？＋

目前提供 Windows 10 / 11 的 x64 版本。macOS、Linux 和 Windows ARM 暂未提供经过验证的安装包。软件已经包含运行环境，无需安装 Node.js。设置中的“形象”支持导入透明静态 PNG / WebP，并可补充闭眼、点击、拖动等动作图。

安装版和免安装版有什么区别？＋

安装版有安装向导、开始菜单入口和卸载功能，适合日常使用。免安装版是一个 EXE 文件，双击即可运行。两种版本都把名字、阅读进度等保存在本机用户数据目录，免安装并不代表不保存数据。

Windows 提示“未知发布者”怎么办？＋

团子目前尚未使用商业代码签名证书，Windows 可能显示未知发布者或 SmartScreen 提示。请确认文件来自本站链接的官方 GitHub Release，并用校验文件核对 SHA-256；如果无法确认来源，请不要运行。

故事、名字和阅读进度会上传吗？＋

这些内容只保存在电脑本机，团子没有账号系统或云同步。使用搜索功能时，会通过默认浏览器访问相应网站；本下载页会向 GitHub 请求公开版本信息，不使用统计或广告脚本。

隐藏后怎么把团子找回来？＋

点击 Windows 系统托盘里的团子图标，或右键选择“显示团子”。隐藏时动画暂停，阅读文字会收起；重新显示后，点菜单里的 R 或按 Ctrl+Alt+R 才会继续展开文字。

下载慢，或者下载按钮没有打开？＋

安装包托管在 GitHub Releases，下载速度受本机网络影响。可以打开最新发布页，在 Assets 中选择 Setup 安装版或 Portable 免安装版。暂时没有第三方镜像。

如何更新或卸载？＋

更新前先从团子菜单点击“退出”，再运行新版安装包；免安装版重新下载新版 EXE 即可。暂不支持自动更新。安装版可从 Windows“已安装的应用”卸载，卸载会保留本机设置和阅读数据。
